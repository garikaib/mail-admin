# FastHTML-Inspired Style Guide

## Direction
The ZimPrices admin UI should feel like a functional control surface wearing the visual language of FastHTML: bright, playful, geometric, and high contrast, while preserving dense administrative workflows.

## Palette
- Canvas: `#f4f3ef` warm off-white for the main application surface.
- Ink: `#151214` for primary text and borders.
- Plum: `#371f35` for the persistent sidebar and deep feature panels.
- Green: `#3fd98f` as the primary action/accent.
- Yellow: `#ffc43d` for secondary actions and attention blocks.
- Purple: `#7470f5` for system/health states.
- Pink: `#df8ed6` for audit/secondary highlights.
- Soft tints: low-alpha versions of each accent for badges, panels, and status rows.

## Shape And Surface
- Use large rounded geometric backdrop blocks, not gradients or glass blur.
- Panels use light fills, dark borders, and a small offset black shadow.
- Primary pills use black or green fills with strong contrast.
- Tables remain compact but get a lighter paper-like treatment.

## Typography
- Use rounded geometric sans typography with heavy section headings.
- Labels are uppercase, small, and tight for scanability.
- Body copy stays compact for admin density.

## Interaction
- Hover states should move surfaces slightly upward and strengthen the offset shadow.
- Focus states use the green accent with a visible ring.
- Existing workflows and information density take priority over decorative layout.
